# PART I — 전략적 기반

---

## 1. 불변의 문장 (수정 금지)

> **보이지 않는다고 느꼈던 인간을, 그의 목소리만으로는 닿을 수 없었던 곳까지 시스템이 대신 전달하여 보이게 만든다.**

나머지는 모두 구현 세부사항이다.

---

## 2. 한 줄 명제

> 서투른 스페인어를 구사하는 한국인 아저씨가 에어프라이어로 고로케를 만들고, 미래지향적인 PWA 인터페이스가 그 과정을 주석 처리한다—나이 든 인간도 AI 기반 콘텐츠 시스템을 통해 세상과 다시 연결될 수 있음을 증명한다.

이것은 요리 채널이 아니다.
이것은 **음식 콘텐츠로 위장한 인간 리부팅 다큐멘터리**다.

---

## 3. 대비 엔진 (왜 이게 작동하는가)

### 3.1 인간 레이어
| 요소 | 효과 |
|---|---|
| 나이 | 신뢰. "우리 아버지 같아." |
| 서투른 스페인어 | 따뜻함. "나를 위해 노력하고 있어." |
| 진짜 손 / 진짜 기름 / 진짜 실수 | 공감. "이건 TV가 아니야." |
| 작은 주방 / 간단한 도구 | 접근성. "나도 할 수 있겠다." |

### 3.2 시스템 레이어
| 요소 | 효과 |
|---|---|
| 깔끔한 PWA 인터페이스 | 인지적 놀라움. "어? 이거 세련됐는데?" |
| 스페인어 우선 주석 | 존중. "내 언어를 위해 만들었네." |
| 고정된 3가지 모드 | 실용성. "따라할 수 있겠다." |
| 타이머 / 단계 / 대체재 | 신뢰. "체계적이고 반복 가능해." |

### 3.3 마법의 공식

```
PAPA FLY = (늙은 인간 + 서투른 언어 + 진짜 주방) × (미래 인터페이스 + 현지 언어 + 명확한 구조)
```

**대비 자체가 콘텐츠다.**
기대: 아마추어 혼란
현실: 체계적 시스템
그 간극에서 시청 시간과 댓글이 발생한다.

## 4. 타겟 시장 (스페인어권 라틴아메리카) — 주장이 아닌 테스트로 접근

라틴아메리카가 "될 것이다"라고 **가정하지 않는다.**
실험 비용이 저렴하기 때문에 **테스트한다.**

| 가설 | 왜 그럴듯한가 | Phase 0에서 어떻게 테스트하나 |
|---|---|---|
| 스페인어권 시청자가 불완전한 스페인어를 용인할 것 | 노력이 진정성으로 읽힘 | 스페인어 댓글 등장 여부 |
| "아저씨 리부팅" 스토리가 순수 레시피 콘텐츠를 이길 것 | 서사가 시청 지속률을 높임 | 평균 시청 지속 시간 vs 기준선 |
| PWA 오버레이가 신뢰와 재방문을 높일 것 | 구조가 인지 부하를 줄임 | PWA 클릭률 + 모드 탭 사용량 |
| 한국 "역수입"이 발생할 수 있음 | 해외 검증이 때때로 반등함 | **별도 측정** (KR 신호 체크) |

---

## 5. 역수입 전략 (v5 수정: 운명이 아닌 측정 가능한 가설로 강등)

역수입을 운명으로 **선언하지 않는다.**
**측정할 가치가 있는 부작용**으로 취급한다.

### 5.1 KR 신호 체크 (별도 대시보드)
**콘텐츠 전략을 변경하지 않고** 다음을 추적한다:

| 지표 | 의미 | 목표 |
|---|---|---|
| KR 댓글 등장 (한국어) | 한국 시청자가 발견함 | 에피소드 8까지 ≥ 3개 댓글 |
| 한국이 상위 지역에 진입 | 알고리즘이 KR에 도달 | 에피소드 8까지 상위 10에 KR 등장 |
| 한국 공유/언급 | 외부 반향 | 1–2개 스크린샷/링크 발견 |

**KR이 나타나지 않으면:** 아무것도 깨지지 않음
**KR이 나타나면:** 기록하고 선택적 연료로 취급, 엔진이 아님

---

## 6. 경쟁 포지셔닝 (카테고리 재정의)

우리는 다음과 **경쟁하지 않는다:**
- 전문 요리 채널
- 먹방/ASMR
- 레시피 데이터베이스
- K-푸드 수출 브랜드

왜냐하면 우리는 아무것도 팔지 않고 요리 권위를 주장하지 않기 때문이다.

우리가 관심을 두고 경쟁하는 대상:
- 절망
- 냉소
- 관성

우리의 진짜 적은 **"나는 너무 늙었어 / 이미 늦었어"**다.

### 왜 100% Uncle인가 (비협상)
1. **단순함이 갈등을 죽인다.**
2. **원한 회계 없음.**
3. **퇴장이 깔끔하다.**
4. Parksy의 보상은 **OS 자체** (재사용 가능한 시스템 + 포트폴리오).

## 12. "80% 포지셔닝" (기대치 엔지니어링)

우리는 레스토랑 완벽함이 아닌 **집에서 80% 맛**을 약속한다.

- 80 약속 → 85 전달 = 기쁨
- 100 약속 → 85 전달 = 실망

**심리학이 허세를 이긴다.**

## 21. D-1 셋업 프로토콜 (v5 추가: "변명 불가" 촬영 체크리스트)

### 21.1 카메라 위치 (표준)
- **각도:** 전면-우측에서 45° 아래로
- **프레임:** 손 + 팬 + 완성 접시
- **얼굴:** Hook + 엔딩에 선택적 등장 (각 5초)

### 21.2 조명 규칙
- 얼굴이 어두우면 → 창문 쪽으로 이동 또는 링라이트 사용
- 기름 반사가 너무 강하면 → 폰을 5–10° 기울이고 조명을 옆으로 이동

### 21.3 오디오 규칙
폰 마이크 OK 조건:
- 거리 < 1.2m
- 주변 소음 낮음

소음이 있으면 → 스페인어 대사를 별도 음성 메모로 녹음 후 오버레이

### 21.4 "실패 방지" 규칙
요리가 실패하면:
- **그래도 업로드한다**
- 제목: "No salió bien… pero aquí está." (잘 안 됐지만… 여기 있습니다)
- **실패가 콘텐츠가 된다, 수치가 아니라**

**응답:** 요리 채널 벤치마킹은 카테고리 오류다.

성공은 셰프 자격이 아닌 시청 시간과 댓글로 측정한다.

### O3: "시장 가정이 검증되지 않았다."
**응답:** 맞다. 그래서 Phase 0가 존재한다.
14일, $0에 가까운 비용, 측정 가능한 기준.

### O4: "단일 실패점 (Uncle)."

Uncle이 멈추면, 실험은 깔끔하게 종료된다.

### O5: "이전에 GPT가 너무 긍정적이었다."
**응답:** 인정한다.
v5는 열정을 다음으로 대체한다:
- KPI
- 킬 스위치
- 문서화된 퇴장
