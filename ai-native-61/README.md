# 61년생 AI네이티브

IT 관련 중요한 것들을 문서로 정리해 저장하고, 이걸 바탕으로 웹페이지를 만드는 프로젝트.

## 폴더 구조

```
ai-native-61/
├── docs/        # IT 문서 저장소 (마크다운). 여기에 정리된 문서를 넣는다.
└── index.html   # (추후) docs의 문서들을 엮은 웹페이지
```

## 문서 저장 규칙

- 파일명은 영어 slug + `.md` (예: `kubernetes-basics.md`, `prompt-engineering.md`)
- 문서 하나 = 주제 하나, 제목은 `#`(H1)로 시작
- 같은 주제가 길어지면 `docs/` 아래 하위 폴더로 묶는다
