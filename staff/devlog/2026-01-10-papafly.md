## Collaborator 등록 및 권한

### 등록 절차
1. 아저씨 GitHub 계정 생성
2. Repository Settings → Collaborators → Add people
3. 아저씨 GitHub username 입력
4. 아저씨가 초대 이메일 수락

### 권한 구조

| 역할 | Staff 도구 | GitHub 커밋 | 설정 변경 |
|------|-----------|-------------|----------|
| 일반 방문자 | ❌ | ❌ | ❌ |
| Staff 비번 아는 사람 | ✅ | ❌ | ❌ |
| **아저씨 (Collaborator)** | ✅ | ✅ | ❌ |
| **Owner (나)** | ✅ | ✅ | ✅ |

### 아저씨 포스팅 워크플로우
```
1. papafly.kr → Staff 클릭
2. 비밀번호 0108 입력
3. HTML 포스팅 도구 선택
4. 템플릿 선택 → 내용 확인 → 파일명 입력
5. 업로드 클릭 → GitHub 페이지 열림
6. GitHub 로그인 (본인 계정, 본인 2FA)
7. Commit changes 클릭
8. 자동 배포 완료 (GitHub Action)
```
