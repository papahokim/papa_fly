# PAPAFLY 아날로그-디지털 아카이브 프로토콜

> 80–90년대 일본 아날로그 자산을 체계적으로 수집·디지털화·해석하여  
> 콘텐츠 소스 + 커머스 기획 엔진 + 세계관 증거로 재구성

- **버전:** 1.0
- **작성일:** 2026-04-23

---

## 1. 목적 정의

80–90년대 일본 잡지·화보·광고·카탈로그 등 아날로그 자산을 **체계적으로 수집·디지털화·해석**해서, PAPAFLY의 **레퍼런스 라이브러리 + 콘텐츠 소스 + 커머스 기획 엔진**으로 사용한다.

---

## 2. 타깃 자산 범위

### 시기·지역
- **시기:** 1980년대 초반 ~ 1990년대 후반 (버블 형성 ~ 붕괴 ~ 여파)
- **지역:** 일본 국내 발행 잡지·무크지·카탈로그·출판물

### 매체 유형
- 패션 잡지 (남성/여성, 스트리트/하이엔드)
- 인테리어/라이프스타일 잡지
- 브랜드/백화점 카탈로그, 무크지
- 광고집 (특정 브랜드/시대별 광고 모음)

### 선별 기준
- 당시 버블 특유의 **스타일·색감·레이아웃**이 잘 드러나는 것
- 지금 기준에서도 **코디·공간·컬러 팔레트로 전용 가능**한 컷이 많은 것
- 중년 남성 아메카지·워크웨어·라이프스타일과 연결 가능한 것

---

## 3. 수집 프로토콜 (Analog Collect)

### 소스 채널
- 일본 옥션, 중고서점, 플리마켓, 온라인 중고 플랫폼

### 획득 정책
- 동일 타이틀/호수는 1부만 확보 (중복 최소화)
- 가격보다 **콘텐츠 밀도**(쓸 컷이 많은지)를 우선 평가

### 카탈로그 기록
획득 시점에 다음을 기록:
- 매체명, 호수, 발행연도
- 주요 테마 (워크웨어, 아메카지, 인테리어 등)
- 상태 (보존 등급)

---

## 4. 디지털화 프로토콜 (Digitize)

### 스캔/촬영 방식
- **원칙:** 훼손 최소화, 고해상도, 후처리 전제
- **방법:** 잡지 펼침 → 조명 고정 → 페이지 단위 촬영
- 전체 페이지 보관용 이미지와, **컷 단위 작업용 이미지**를 분리

### 파일 구조 예시

```
/archive/jp-mag/
  /1987/popeye_1987_05/
    page_01_full.jpg
    page_01_cut_01.jpg
    page_01_cut_01.meta.json
```

### 메타데이터 스키마 (meta.json)

```json
{
  "year": 1987,
  "magazine": "Popeye",
  "issue": "1987-05",
  "page": 1,
  "cut_id": "01",
  "category": ["menswear", "workwear"],
  "tags": ["denim", "layering", "navy", "wide-pants"],
  "comment": "오늘 기준으로도 통하는 상·하의 비율, 색감 조합 좋음",
  "candidate_for_content": true,
  "candidate_for_coord": true
}
```

## 5. 해석/태깅 프로토콜 (Translate & Index)

### 태그 체계
각 컷에 대해 최소한 다음을 태깅:
- **타임라인:** 연도, 계절
- **카테고리:** 패션/인테리어/소품/광고
- **스타일 요소:** 실루엣, 레이어링, 비율, 패턴, 컬러
- **연결 가능성:**
  - 현재 빈티지/중고 (이미 보유/구할 수 있는 것)
  - 현재 신상/브랜드 (제휴 가능/이미 팔고 있는 것)

### 활용 플래그

| 플래그 | 의미 |
|--------|------|
| `candidate_for_content` | 콘텐츠 소재로 바로 쓸 수 있는 컷 |
| `candidate_for_product` | 상품/코디와 직접 연결할 계획 |
| `laneA_only` | 아카이브 설명 전용 (상품 연동 없음) |
| `laneB_bridge` | 브리지 콘텐츠용 (아카이브 ↔ 상품 연결) |

## 6. 활용 전략 (Use)

### 콘텐츠 활용
- **아카이브 해설 영상:**
  - "1987년 ○○잡지 한 컷에서 오늘 쓸 수 있는 포인트 3개"
  - "이 광고의 컬러 팔레트를 2026년 셔츠/자켓에 옮기면"
- **브리지 콘텐츠:**
  - 왼쪽: 잡지 컷 (일부 인용 + 설명)
  - 오른쪽: 오늘의 코디/상품 (중고/신상)
  - 메시지: "이때의 감각을 지금 이렇게 입을 수 있다."

### 커머스/기획 활용
- **코디 세트 설계:** 특정 화보 기준 상의/하의/아우터/소품 구성 → Lane B 재고 매칭
- **제품 개발/콜라보 참고:** 브랜드와 협업 시 "이 시대 레퍼런스 기반 캡슐 컬렉션" 제안

## 7. 저작권·법적 가드레일

1. **프라이빗 DB vs 공개**
   - 프라이빗: 전체 페이지 스캔/컷 — 내부 연구·기획용
   - 공개: 일부 컷/저해상 크롭 + 해설 중심. 원본 전면 복제 회피

2. **상업 영역은 '재구성 결과물'에 초점**
   - 실제 판매 페이지: 잡지 이미지 전면 사용 금지
   - 화보에서 추출한 **스타일/컬러/실루엣**만 가져와
     내 사진/영상/상품으로 재구성

3. **출처 표기** (필요 시)
   - 콘텐츠에서 원본 언급 시 잡지명/연도 텍스트 표기

## 8. 이 모듈이 PAPAFLY에 기여하는 것

| 레인 | 기여 |
|------|------|
| **Lane A (Archive)** | 80-90s 아날로그 자산이 "팔지 않는 세계관"의 증거 → "이 시대를 통째로 읽고 있는 사람" 권위 |
| **Lane B (Authorized Edition)** | 모든 상품 기획의 출발점이 "아카이브 레퍼런스" → 단순 리셀링 아닌 **아카이브 기반 재해석 상품** |
| **콘텐츠 엔진** | 잡지 1권이 여러 콘텐츠/코디/상품 기획으로 분해 → 지속 가능한 아이디어 소스 |
