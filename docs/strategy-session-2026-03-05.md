# 파파플라이 전략 세션 — 2026-03-05

## 개요

파파플라이 비즈니스 모델 및 전략에 대한 검토 세션.

---

## 프로젝트 구조

### 파파플라이 (papafly.kr)
- **컨셉**: 재패니즈 패치 — 일본의 시간을 입다
- **형태**: 일본 빈티지 문화 쇼핑몰
- **소싱**: 일본 현장 플리마켓/중고 직접 소싱
- **커머스**: 쿠팡윙 연계 + 독립 도메인

### 호야당 (독립 도메인)
- **컨셉**: 베이커리 + 에어프라이어 간편 레시피
- **형태**: 물성 기반 베이커리 프로젝트
- **유튜브 소재**: 에어프라이어 활용 간편 조리법

## 핵심 비즈니스 모델: 루프백 구조

```
YouTube 영상
  ↓  (궁금증 유발, 세계관 전달)
파파플라이 사이트 (papafly.kr)
  ↓  (YouTube가 못 주는 것 — 실물, 소장, 큐레이션 경험)
구매 / 소장
  ↓  (구매자가 영상으로 돌아옴, 다음 소싱 콘텐츠 기다림)
YouTube 영상  ← 루프 반복
```

> **핵심 명제**: 유튜브는 경험을 보여주고, 쇼핑몰은 경험을 판다.

- 알고리즘 종속 탈피: 독립 도메인이 유튜브 리스크를 분산
- 검증된 구조: ZOZOTOWN x YouTube, 29CM 감성 커머스와 유사

## 전문가 평가 요약

### 승산 있다 — 조건부

**강점**
- "64세 교양인 + 일본 빈티지 직소싱" 포지션은 국내 구조적 공백
- 유튜브 ↔ 커머스 루프백 모델 자체는 검증된 구조
- 일본어 가능 = 현장 소싱 비용/번역 0, 진정성 확보

**리스크**
- 자원 분산: 베이커리·웹툰·음원·방송·쇼핑몰 병렬 운영 시 전부 중간에 머묾
- 쿠팡윙 한계: 빈티지 감성을 쿠팡 UI에서 전달 불가 → 독립 사이트가 세계관 허브여야 함
- 초기 재고 리스크: 소량 큐레이션 → 회전률 먼저

## 메타 레이어: 브랜치 시스템

### 개념

나는 주인공이 아니다. 나는 시스템 설계자다.

```
친구 A (호야당 베이커리)  ─┐
친구 B (파파플라이 빈티지) ─┤→ 각자 시스템 설계 (플랫폼, 도메인, 루프)
친구 C (다음 브랜치)       ─┘
                              ↓
              "평범한 사람이 사업 만드는 과정"
                        메타 방송
                              ↓
                    시청자 중 누군가가
                  "나도 저렇게 해달라"
                              ↓
                        다음 브랜치
```

### 왜 착취가 아닌가

| 주체 | 얻는 것 |
|------|---------|
| 친구들 | 플랫폼, 시스템, 노출 — 혼자였으면 불가능한 것들 |
| 나 | 콘텐츠 소재 무한 공급, 방법론 검증 |
| 시청자 | 리얼한 창업 드라마 + 배움 |
| 메타 채널 | 브랜치 늘수록 콘텐츠 늘어남 |

친구들이 잘 돼야 메타 채널이 산다. 이해관계가 완전히 일치한다.

### 내 직함과 IP

> 나는 평범한 사람의 가능성을 시스템으로 꺼내주는 사람이다.

이것이 방법론이고, 결국 팔 수 있는 것이다.
브랜치가 쌓일수록 방법론이 검증되고, 방법론이 곧 독립적인 IP가 된다.

### 선행 사례 비교

- **Y Combinator** — 스타트업 배치 자체가 브랜드
- **MrBeast** — 팀원 스토리를 콘텐츠화
- **Gary Vee** — 과정 공개가 제품

차이점: 셋 다 자기 자신이 주인공. 이 모델은 주인공이 여러 명이고 설계자는 보이지 않는다. 더 확장성 있다.
