# 공간 엔지니어링 아이디어 — 청소×리팩토링×부동산/인테리어/콘텐츠 통합 파이프라인 (2026-07-28)

> 출처: Gemini 대화 (박씨 원본, 그대로 보존). Claude Code가 요청받아 papafly 레포에 저장.
> 성격: 아이디어 원자재(raw idea) 로그. papafly 전략에 즉시 반영된 건 아님 — 헌법 제1조(레포=소설) 원칙에 따라 삽질/발상 단계도 그대로 남긴다.

## 1. 발단 — 청소를 리팩토링/공간 엔지니어링으로 재해석

박씨가 청소를 좋아하는 성향을 소프트웨어 개념(리팩토링/리스트럭처링/공간 엔지니어링)으로 재해석할 수 있는지 질문. Gemini 응답 요지:

- **Garbage Collection & State Reset (비우기)** — 메모리 누수 정리, 캐시 초기화에 대응
- **Refactoring** — 외부 동작(공간 기능)은 유지, 내부 구조(수납 위치)만 개선
- **Restructuring** — 가구 배치/동선을 아예 새로 짬. 병목 해소, 도메인 재정의
- **Space Engineering & UX** — 사용자-공간 인터페이스 최적화, 인지적 마찰(Friction) 최소화

결론: "청소를 좋아하는 사람은 공간을 실행환경(Runtime), 물건을 데이터/모듈, 동선을 알고리즘으로 보는 시각을 가진 것."

## 2. 확장 — 80년대 일본 주부 잡지(美しい部屋/主婦の生活) 디지털화 아이디어

박씨의 기존 구상: 80년대 일본 가정주부 잡지(우츠크시헤야, 슈후노세이카츠) 류의 수납/인테리어 노하우를 디지털화하여 인테리어에 접목.

Gemini가 제시한 3단계 파이프라인:

1. **잡지 디지털화 = 공간 패턴 라이브러리** — "데드 스페이스 활용법", "동선 최적화" 등 기사를 태깅/DB화 → 모듈형 인테리어 패턴 인덱스
2. **인테리어 = 공간 시스템 아키텍처** — 추출한 패턴을 물리 공간(가구 배치, 수납 구획, 동선)에 이식
3. **청소 = Continuous Maintenance (DevOps)** — 구축된 시스템이 무너지지 않게 유지하는 지속 운영

## 3. 최종 구상 — 부동산×인테리어×콘텐츠 통합 + ADB/APK→CAD→ComfyUI 렌더링 파이프라인

박씨의 핵심 아이디어:

> "공간이라는 개념으로 연결되니까 부동산 업자, 콘텐츠, 인테리어 업자가 다 연결된다.
> 이걸 통합시키고, 물건을 ADB/APK로 사진 찍어서 캐드 도면처럼 나오면,
> AI 코어로 인테리어링해서 캐드처럼 만들고 ComfyUI로 렌더링하면 프로 마감이 가능할 것 같다."

### 3.1 테크 파이프라인 (4단계)

```
[Android 디바이스 (APK/ADB)]
       │ 사진 / Depth / 공간 센서
       ▼
[AI Core: Spatial Parser] ──► 2D/3D CAD 도면 (JSON / DXF)
       │                              │ (+ 80년대 수납 알고리즘 이식)
       ▼                              ▼
[ComfyUI Headless Engine] ◄── ControlNet (Depth / LineArt) + Custom LoRA
       │
       ▼
[최종 결과물: 포토리얼리스틱 인테리어 렌더링 + 실측 도면]
```

- **① 데이터 캡처**: 모바일 카메라 + Depth API 등으로 공간 사진/센서 데이터 수집 (3D 스캐너 불필요)
- **② AI Core → CAD 벡터화**: 비전 인식(SAM, Depth-Anything 등)으로 면적/기둥/창문/문 위치 파싱 → 2D/3D CAD(DXF/JSON) 변환. 여기에 80년대 잡지에서 추출한 고밀도 수납/동선 패턴을 자동 배치 로직으로 이식
- **③ ComfyUI 렌더링**: CAD 도면(LineArt/Depth)을 ControlNet 입력으로 사용, Flux/SDXL + 커스텀 LoRA로 재질/조명 반영한 포토리얼리스틱 렌더링
- **핵심 경쟁력**: CAD 도면을 ControlNet 뼈대로 고정하기 때문에 일반 AI 이미지 생성과 달리 치수/형태가 뭉개지지 않음 (mm 단위 고정 + 재질만 입힘)

### 3.2 비즈니스 생태계 (3자 매칭)

| 이해관계자 | 제공 가치 | 효과 |
|---|---|---|
| 부동산 업자 | 공실/낙후 매물 가상 홈스테이징, 공간 효율성 점수 + 리모델링 예상 렌더링 | 계약 체결률 상승, 리모델링 프리미엄 |
| 인테리어 업자 | AI 추출 CAD 실측 도면/자재 레이아웃, 클라이언트 상담용 고화질 렌더링 | 현장 실측 시간 절감, 상담 피드백 루프 단축 |
| 콘텐츠(미디어) | "비포(어지러운 공실)→애프터(80s 고밀도 수납)" 타임랩스/3D 룸투어 | 정리/인테리어 숏폼 바이럴 |

### 3.3 왜 "프로 마감"이 가능한가

1. **정밀도 제어** — CAD 도면 기반 ControlNet(LineArt/Depth) 고정 → 재질만 디퓨전으로 입힘
2. **패턴 DB 탑재** — 예쁘기만 한 인테리어가 아니라 80년대 일본 잡지 아카이브 기반 "실제 살기 좋은 동선+수납력" 철학이 배치 로직에 개입
3. **완전 자동화** — 모바일 촬영(ADB/API) → 백엔드 headless ComfyUI 파이프라인 즉시 실행 → 수 분 내 완품 반환
