# PART I — STRATEGIC FOUNDATION

---

## 1. The Immutable Sentence

> **We make visible a human who felt invisible, by letting a system carry what his voice alone could not.**

Everything else is implementation detail.

---

## 2. One-Line Thesis

> A Korean uncle, speaking broken Spanish, makes air-fryer croquettes while a futuristic PWA interface annotates the process—proving aging humans can reconnect with the world through AI-assisted content systems.

This is not a cooking channel.
This is a **human reboot documentary** disguised as food content.

---

## 3. The Contrast Engine

### 3.1 The Human Layer
| Element | Effect |
|---|---|
| Age | Trust. "He's like my father." |
| Broken Spanish | Warmth. "He's trying for me." |
| Real hands / real oil / real mistakes | Relatability. "This isn't TV." |
| Small kitchen / simple tools | Accessibility. "I can do this." |

### 3.2 The System Layer
| Element | Effect |
|---|---|
| Clean PWA interface | Cognitive surprise. "Wait—this is sophisticated." |
| Spanish-first annotations | Respect. "Built for my language." |
| 3 fixed modes | Utility. "I can copy this." |
| Timers / steps / substitutes | Trust. "Organized, repeatable." |

### 3.3 The Magic Formula

```
PAPA FLY = (Old Human + Broken Language + Real Kitchen) × (Future Interface + Native Language + Clear Structure)
```

---

## 4. Target Market

Spanish LatAm — Treated as a Test, Not a Claim.

| Hypothesis | Why Plausible | How We Test |
|---|---|---|
| Spanish-speaking audiences will tolerate imperfect Spanish | Effort reads as sincerity | Spanish comments appear |
| The "uncle reboot" story will outperform pure recipe content | Narrative increases retention | Avg view duration vs baseline |
| PWA overlay will raise trust + repeat viewing | Structure reduces cognitive load | PWA click-through + mode tab usage |

# PART III — CONTENT OS

---

## 8. Episode Format

| Segment | Duration | Content |
|---|---:|---|
| Hook | 0:00–0:08 | Identity + "Español… un poco." + today goal |
| Setup | 0:08–0:30 | Ingredients shown + PWA overlay cut |
| Process | 0:30–2:00 | Hands + cooking + 2–4 PWA inserts |
| Result | 2:00–2:30 | "80% sabor en casa" |
| CTA | 2:30–2:45 | PWA link + thanks |

**Total:** 2–3 minutes (Phase 0)

---

## 9. The Three Modes

| Mode | Device | Message |
|---|---|---|
| Air Fryer | 에어프라이어 | "10–12 min, 80% sabor" |
| Microwave | 전자레인지 | "Emergency, 4 min" |
| Pan | 프라이팬 | "No special device" |

**No fourth mode.** Complexity is the enemy of execution.

---

## 10. The "80% Positioning"

We promise **80% taste at home**, not restaurant perfection.

- Promise 80 → deliver 85 = delight
- Promise 100 → deliver 85 = disappointment

---

## 11. Spanish Protocol

### 11.1 The 10-Sentence Pilot Set
| # | Spanish | Purpose |
|---:|---|---|
| 1 | Hola, soy ___ de Corea. | Identity |
| 2 | Español… un poco. Perdón. | Expectation reset |
| 3 | Hoy hacemos croquetas estilo coreano. | Topic |
| 4 | Ingredientes fáciles, del mercado local. | Accessibility |
| 5 | Objetivo: 80% sabor en casa. | Promise |
| 6 | Modo: Air fryer. | Mode |
| 7 | Tiempo: ___ minutos. | Time |
| 8 | Paso uno… paso dos… | Steps |
| 9 | Mira la receta completa en el link. | CTA |
| 10 | Gracias. Nos vemos. | Close |

### 11.2 The Fluency Rule
We do **not** chase fluency. We chase **closeness**.

- **Allowed:** natural improvement over months
- **Forbidden:** "professional presenter mode"

# PART IV — PWA SPEC

---

## 12. PWA Goal

The PWA is not a product.
It is a **trust amplifier** and **retention tool**.

- One page per episode
- Spanish-first with (한글) hints
- 3 tabs (Air/Micro/Pan)
- Steps + timers + substitutes
- Mobile-first, **3 taps max** to any info

# PART V — PHASE MODEL

---

## 14. Phase 0 — Signal Detection

**Deliverables:**
- 3 videos uploaded
- 3 PWA pages live
- Analytics active
- 14 days observation

**Goal:** detect signal, not make money.

---

## 15. Kill-Switch (Phase 0)

Must meet **2 of 3**:

| KPI | Target |
|---|---|
| Spanish comments | ≥ 10 |
| PWA clicks | ≥ 50 |
| Avg view duration | ≥ 35% |

**Decision Logic:**
- If <2 met: Diagnose → iterate format → retry once
- If retry fails: Pause project

**Pause is success if learning is extracted.**

---

## 16. Phase 1 — Format Validation

- 8 videos total
- 1–2/week cadence
- A/B test hooks + thumbnails

---
